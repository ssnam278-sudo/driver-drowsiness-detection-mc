# Deploy the browser demo

This repository now includes `app.py`, a Streamlit web interface for the
temporal drowsiness decision layer.

## Streamlit Community Cloud

1. Push this repository to GitHub.
2. Open <https://share.streamlit.io> and choose **New app**.
3. Select the repository, branch, and set the main file to `app.py`.
4. Deploy.

The resulting URL will be a public `https://*.streamlit.app` link.
